# PC Build AI Assistant
**Автор:** Гулійчук Артем, група ІПЗс-25-1

## Мета проєкту (Elevator Pitch)
Збірка комп'ютера — це процес, що супроводжується ризиком апаратних конфліктів. ШІ-асистент вирішує проблему неочевидної несумісності комплектуючих, використовуючи ШІ-паттерн Function Calling. Модель аналізує конфігурацію та викликає SQL-запити до бази даних для точної технічної валідації до покупки.

## Цільова аудиторія
Ентузіасти, геймери та студенти технічних спеціальностей, які самостійно збирають ПК, але не хочуть витрачати години на вивчення мануалів.

## Інструкція із запуску
1. Встановіть Node.js та PostgreSQL.
2. Склонуйте репозиторій та виконайте `npm install`.
3. Створіть базу даних `pc_assistant_db` та виконайте SQL-скрипти з документації для створення таблиць.
4. Перейменуйте файл `.env.example` на `.env` та впишіть свій ключ від Groq API та дані доступу до БД.
5. Запустіть сервер командою `npm start`.
6. Відкрийте файл `public/index.html` у браузері.

## Економіка проєкту (Cost Awareness)
* **Середнє споживання:** ~300 вхідних та 150 вихідних токенів на запит.
* **Використовувана модель:** `llama-3.3-70b-versatile`.
* **Вартість утримання:** $0.00 на місяць.
* **Обґрунтування рішення:** Під час розробки та тестування було виявлено регіональні блокування (помилка 429) та нульові квоти у Free Tier від попереднього провайдера (Google Gemini). Було прийнято архітектурне рішення мігрувати бекенд на Groq API. Це дозволило зберегти функціонал інтелектуального виклику функцій бази даних, зменшити затримку (latency) до <500 мс та звести вартість утримання проєкту до нуля в рамках розробницьких лімітів.
