# PC Build AI Assistant
**Автор:** Артем, студент групи ІПЗс-25-1, ЗВО "Університет Короля Данила"

## Мета проєкту (Elevator Pitch)
Збірка комп'ютера — це процес, що супроводжується ризиком апаратних конфліктів. Наш ШІ-асистент вирішує проблему неочевидної несумісності комплектуючих, використовуючи ШІ-паттерн Function Calling. Модель аналізує конфігурацію та викликає SQL-запити до бази даних для точної технічної валідації до покупки.

## Цільова аудиторія
Ентузіасти, геймери та студенти технічних спеціальностей, які самостійно збирають ПК, але не хочуть витрачати години на вивчення мануалів.

## Інструкція із запуску
1. Встановіть Node.js та PostgreSQL.
2. Склонуйте репозиторій та виконайте `npm install`.
3. Створіть базу даних `pc_assistant_db` та виконайте SQL-скрипти з документації для створення таблиць.
4. Перейменуйте файл `.env.example` на `.env` та впишіть свій ключ від Gemini API та дані доступу до БД.
5. Запустіть сервер командою `npm start`.
6. Відкрийте файл `public/index.html` у браузері.
